# LangGraph

LangGraph 用图来描述有状态的流程，适合需要分支、循环或持久化状态的应用。

## 核心组成

- **State**：节点之间共享和更新的数据。
- **Node**：执行工作的函数，例如调用模型或工具。
- **Edge**：决定节点之间的流向；条件边可以根据状态选择分支。

流程通常从起始节点开始，经过一个或多个节点，最后到达结束节点。条件边可以根据当前状态决定下一步，也可以把流程连接成循环。

## 能处理什么

- **分支与循环**：按条件路由，重复执行步骤。
- **状态流转**：在节点之间传递和更新共享状态。
- **持久化**：通过 checkpointer 保存运行状态。
- **暂停与恢复**：使用 `interrupt()` 暂停流程，等待外部输入后继续。

## 与 Agent 的关系

LangChain 的 `create_agent` 基于 LangGraph 实现，封装了常见的“模型判断 → 工具执行 → 模型继续处理”循环。需要定制更复杂的状态、分支和暂停恢复逻辑时，可以直接使用 LangGraph 定义流程。
